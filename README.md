# Data Structures 

## 📌 Overview

This repository focuses on building some of Data Structures using C++, without relying on the built-in implementations for the custom data structures.

It includes implementing Linked Lists and Dynamic Arrays, building Stack and Queue structures on top of them, and applying these concepts in practical projects.

## 🏗️ Implementations

### 1. Linked List
- Implemented a Linked List from scratch.
- Created a custom Node class to manage data and node connections.
- Built Stack and Queue implementations using the Linked List.

### 2. Dynamic Array
- Implemented a Dynamic Array from scratch.
- Built Stack and Queue implementations using the Dynamic Array.

### 3. Stack Applications ( [clsMyString.h](./AppsOnDataStructures/clsMyString.h) )

**Text Editor – Undo & Redo**
- A simple text editor application that uses two stacks to implement Undo and Redo functionality.
- Tracks previous and future text states to manage changes.

### 4. Queue Applications ( [clsQueueLine.h](./AppsOnDataStructures/clsQueueLine.h) )

**Ticketing / Queue Management System**
- A practical application that simulates a ticketing system.
- Uses a Queue to manage customers and process them in order (FIFO – First In, First Out).

## 🛠️ Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Data Structures
- Dynamic Memory Allocation
- Pointers and References

## 🎯 Learning Objectives

- Understanding how fundamental Data Structures work internally.
- Practicing implementation using pointers and dynamic memory allocation.
- Understanding the relationship between Data Structures and Abstract Data Types (ADTs).
- Applying Data Structures to solve practical problems.
- Strengthening problem-solving and programming skills.
